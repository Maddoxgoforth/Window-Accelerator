# Logan & Trey — Window Accelerator Funnel

Marketing funnel for Logan & Trey's window cleaning mentorship offer, built
with Next.js 16 (App Router), TypeScript, and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build (also type-checks) |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |

## Pages

| Route | Purpose |
|---|---|
| `/` | Main funnel — VSL, story, and application form |
| `/offer` | Starter Kit ($30 one-time) — self-serve sales page |
| `/thank-you-mid` | Pro ($500) — post-booking, watch-before-your-call page |
| `/thank-you` | VIP ($2,000) — post-booking, watch-before-your-call page |

## Placeholders

Every video, photo, form, checkout, and booking link is currently a
labeled placeholder — nothing real has been added yet. See
[`docs/funnel/asset-manifest.md`](./docs/funnel/asset-manifest.md) for the
complete list of what to collect from Logan & Trey, and
[`CLAUDE.md`](./CLAUDE.md) for how to swap a placeholder for the real
thing once it arrives.
